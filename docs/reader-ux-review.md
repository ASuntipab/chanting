# UX หน้าท่องบทสวด และข้อเสนอไอคอน

ขอบเขต: จัดลำดับคำสั่ง ชื่อที่ผู้ใช้เห็น การเข้าถึง และพื้นที่กด โดยคงสี ธีม แบบพื้นผิว และชุดไอคอนเดิม ไม่เปลี่ยนภาพลักษณ์ของแอป

## สิ่งที่ปรับ

- แผงหลักเหลือเลือกหน้า เล็กลง ใหญ่ขึ้น ตั้งค่าการอ่าน ฟังคำอ่าน และเสียงพระสวด ตัดปุ่มนับรอบออกและบันทึกการสวดที่หน้าสุดท้าย
- ย้ายแบบตัวหนังสือ การจัดข้อความ รูปแบบคำอ่านบาลี เปลี่ยนสีพื้นหลัง ตั้งค่าเสียงอ่าน และวิธีใช้งาน ไปอยู่ในตั้งค่าการอ่าน
- การตั้งค่าเดิมบันทึกทันทีและจำข้ามการเปิดแอป ปุ่ม “เสร็จแล้ว” ปิดหน้าตั้งค่า ไม่ต้องกดบันทึกซ้ำ
- ใช้คำสั้น “เล็กลง / ใหญ่ขึ้น” แทน A-/A+ และใช้ “ตั้งค่า / ซ่อนปุ่ม” บนหน้าหลัก โดยคงชื่อเต็มให้โปรแกรมอ่านหน้าจอ ไม่ต้องเรียนรู้การปัดก่อนใช้งาน
- อธิบายตัวเลือกเฉพาะทาง เช่น คำอ่านภาษาไทย และบาลีอักษรไทยที่มีจุดพินทุ
- แยกชื่อฟังคำอ่านออกจากเสียงพระสวด และจัดตัวเลือกเสียงที่ใช้ไม่บ่อยไว้ในส่วนพับเก็บของเครื่องเล่น
- ปุ่มหลักมีพื้นที่กดสูงอย่างน้อย 48 พิกเซล ปิดการกดเพิ่ม/ลดเมื่อถึงขอบเขตขนาดตัวหนังสือ
- หน้าตั้งค่าเลื่อนได้บนจอเตี้ย รองรับ Tab, Shift+Tab, Escape และคืนโฟกัสเมื่อปิด ป้องกันการกดปุ่มด้านหลังหน้าตั้งค่า
- คีย์บอร์ดบนปุ่มไม่เปลี่ยนหน้าบทสวดโดยไม่ตั้งใจ ตัวเลือกหน้าอ่านออกเป็น “หน้า … จาก …” สำหรับโปรแกรมอ่านหน้าจอ

- ปุ่มกลับอยู่ซ้ายทั้งสองโหมด ย้ายก่อนหน้า เลขหน้า และปุ่ม “ปัด ›” ขึ้นแถวบนในโหมดอ่าน และตัดส่วนท้ายหน้าออก หน้าสุดท้ายเปลี่ยนปุ่มเป็น “จบ ✓”
- เว้นพื้นที่แถวบนให้ชื่อบทไม่ถูกปุ่มบัง และตัดบรรทัดคำแนะนำการปัดที่กินพื้นที่ออก
- แสดงตัวเลขเป็น 0–9 ทั่วแอป รวมบทสวด พระไตรปิฎก บันทึกการสวด และการ์ดแชร์ พร้อมรองรับการค้นหาข้อมูลเดิมที่มีเลขไทย
- ใช้ภาพเวกเตอร์เครื่องหมาย + ในปุ่มเพิ่ม เพื่อให้กึ่งกลางไม่ขึ้นกับตำแหน่งตัวอักษรของฟอนต์

## ประเมินไอคอนปัจจุบัน

เป็นอีโมจิผสมอักขระ เช่น ⛶ และ SVG บางตำแหน่ง ไม่ได้ใช้คลังไอคอนเดียวกันทั้งหมด

ความเห็นด้าน UX: ไม่จำเป็นต้องเรียกว่าโบราณ อีโมจิเข้ากับบรรยากาศเป็นมิตรและใช้เป็นองค์ประกอบของหมวดหมู่ได้ แต่ใช้แทนคำสั่งเพียงอย่างเดียวได้ไม่ดี เช่น 🎨 อาจหมายถึงวาดรูปหรือเปลี่ยนสี และ 🎛️ อาจไม่ทำให้ผู้ใช้รู้ว่าเป็นตั้งค่าเสียง จุดที่ควรแก้ก่อนคือความหมายและข้อความกำกับ

## ทางเลือกที่ค้นคว้า

| ชุด | ลักษณะ | ความเหมาะสมกับแอปนี้ |
| --- | --- | --- |
| Material Symbols | มี Outline, Rounded, Sharp และปรับความหนา/เติมสีได้ | ตัวเลือกแรกหากต้องการคำสั่งมาตรฐานและเส้นที่อ่านชัด เลือก Rounded ความหนาปานกลางขึ้นไป |
| Phosphor | มี Thin, Light, Regular, Bold, Fill, Duotone | เหมาะหากอยากได้เส้นที่ดูเป็นมิตร ใช้ Regular หรือ Bold แทนเส้นบางมาก |
| Lucide | ไอคอนเส้น ปรับขนาดและความหนาได้ | เหมาะกับหน้าที่เรียบและเป็นระบบ ควรเลือกความหนาที่อ่านชัดบนมือถือ |
| Heroicons | มี Outline และ Solid ในขนาดที่ออกแบบมาให้ต่างกัน | เหมาะกับชุดคำสั่งพื้นฐานและต้องการตัวเลือกไม่ซับซ้อน |

ข้อเสนอ: คงดอกบัวและอีโมจิที่ใช้สร้างบรรยากาศไว้ หากจะเปลี่ยนในรอบถัดไป ให้ใช้ชุดเดียวเฉพาะปุ่มคำสั่ง โดยเริ่มพิจารณา Material Symbols Rounded และมีคำไทยกำกับเสมอ ดาวน์โหลดเฉพาะ SVG ที่ใช้เก็บไว้ในแอปเพื่อรองรับออฟไลน์ รอบนี้ยังไม่ติดตั้งหรือเปลี่ยนชุดไอคอน

ชื่อที่แนะนำ: “ขยายตัวหนังสือ”, “ตั้งค่าการอ่าน”, “ฟังคำอ่าน”, “เสียงพระสวด”, “สวดจบแล้ว”, “เปิดแผงควบคุม” แทนการให้ผู้ใช้แปลความหมายของไอคอนเอง

แหล่งข้อมูลผู้พัฒนา:

- [Material Symbols](https://developers.google.com/fonts/docs/material_symbols)
- [Phosphor](https://github.com/phosphor-icons/core)
- [Lucide](https://lucide.dev/) และ [Accessibility](https://github.com/lucide-icons/lucide/blob/main/docs/how-to/accessibility.md)
- [Heroicons](https://heroicons.com/)

การตรวจด้วยเบราว์เซอร์และชุดทดสอบช่วยยืนยันการทำงาน แต่ยังไม่ได้ทดสอบกับเด็กหรือผู้สูงอายุจริง จึงยังไม่สรุปว่าทุกวัยเข้าใจได้เท่ากัน ควรทดลองให้ผู้ใช้หาปุ่มขยายตัวหนังสือ ตั้งการจัดกลาง เปิด/ซ่อนแผง และบันทึกสวดจบโดยไม่บอกวิธีก่อน

## แผงเสียงพระสวด

เครื่องเล่นใช้พื้นที่แผงควบคุมเดิม ไม่ลอยซ้อนทับปุ่มอ่าน แสดงชื่อเสียงและแหล่งที่มาครั้งเดียว ปุ่มหลักเป็นเล่น/พัก ย้อนและข้าม 10 วินาที ตัวเลือกเสียง ความเร็ว และวนซ้ำอยู่ในส่วนพับได้ ปิดแผงแล้วกลับไปปุ่มอ่าน ส่วนเล็กลง/ใหญ่ขึ้นเอากรอบของกลุ่มออกให้เหลือกรอบของแต่ละปุ่ม
